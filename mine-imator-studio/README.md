# Mine-Imator Studio 🎬🧱

استوديو أنيميشن لماين كرافت يشتغل كامل داخل المتصفح — بلا تثبيت أي برنامج، وبنفس روح برنامج **Mine-Imator**:
شخصية بلوكية مفصليّة، تايم لاين كي فريمات، بناء عوالم بالبلوكات، كاميرا متحركة، وتصدير فيديو.

A Minecraft animation studio that runs entirely in the browser — a web take on **Mine-Imator**:
a rigged blocky character, a keyframe timeline, a block world builder, animated camera and video export.

## التشغيل / Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # إنتاج نسخة جاهزة في dist/
```

## الميزات / Features

| الميزة | التفاصيل |
| --- | --- |
| 🧍 شخصية بلوكية | موديل كلاسيكي أو نحيف، هيكل بعظام: الجسم، الرأس، الذراعين، الساقين |
| 🎨 مظهر مرن | ألوان قابلة للتغيير، أنماط قميص، عباءة، عصابة رأس، لحية، وجلود جاهزة |
| 📥 استيراد جلود | أي ملف PNG قياسي 64×64 (وأيضاً 64×32 القديم) يلبسه الشخصية فوراً |
| 🧱 بناء العوالم | 29 نوع بلوك، بناء/حذف بالضغط، ثيبات جاهزة: سهول، تلال، صحراء، ثلج، نذر، استوديو، فراغ، جزر عائمة |
| ⏱️ تايم لاين | كي فريمات لكل عظمة، سحب وتعديل، تنعيم (ناعم/خطي/ثابت)، تسجيل تلقائي |
| 🎞️ حركات جاهزة | مشي، جري، قفز، رقص، تلويح، لكمة، انحناء، جلوس، دوران، شقلبة… |
| 🎥 كاميرا | كي فريمات كاميرا + حركات جاهزة (دوران، زوم، مسار، رافعة) وواجهات جاهزة (أمامي/جانبي/علوي/بورتريه) |
| ⤓ تصدير | فيديو WebM من المتصفح، صور PNG لكل الإطارات داخل ZIP، أو ملف المشروع JSON |
| 💾 مشروع | حفظ/فتح JSON + حفظ تلقائي في المتصفح، وتراجع Ctrl+Z لتعديلات العالم |
| 🌐 لغة | واجهة عربية (RTL) وإنجليزية بزر تبديل |

## الاختصارات / Shortcuts

| المفتاح | الوظيفة |
| --- | --- |
| `Space` | تشغيل / إيقاف |
| `←` `→` | فريم للأمام أو الخلف (`Shift` = 10 فريمات) |
| `K` | إضافة كي فريم للعظمة المحددة |
| `Delete` | حذف الكي المحدد |
| `Ctrl+S` | حفظ ملف المشروع |
| `Ctrl+Z` | تراجع عن تعديلات البلوكات |
| `Ctrl+E` | نافذة التصدير |

## بنية المشروع / Layout

```
src/
  blocks.js   مكتبة البلوكات + رسم النسيج برمجياً (بلا أي صور خارجية)
  skin.js     رسم أطلس جلد 64×64 قياسي + عباءة 64×32
  rig.js      بناء الشخصية وعظامها وترتيب UV
  anim.js     مخزن الكي فريمات، الاستيفاء، التنعيم، والحركات الجاهزة
  export.js   تصدير فيديو (MediaRecorder)، صور PNG (JSZip)، وملفات
  i18n.js     نصوص عربي/إنجليزي
  main.js     المشهد، بناء العالم، التايم لاين، وربط الواجهة
```

كل الرسومات (البلوكات والجلود والأيقونات والسماء) تُرسم وقت التشغيل على Canvas — لذلك المشروع خفيف وما فيه ملفات أصول.
